# Project State

## Overview
This is a premium, zero-cost (free-tier optimized) Pet Shop website built with Next.js (App Router), Tailwind CSS, Framer Motion, and Payload CMS (PostgreSQL). The goal is to deliver an extremely high-end UI ("v3 redesign") featuring custom cursors, magnetic buttons, liquid glass effects, and seamless animations, while remaining deployable on free tiers (Vercel + Neon).

## Architecture
- **Framework**: Next.js 15 (React 19)
- **Styling**: Tailwind CSS + `cn` utility (clsx/tailwind-merge)
- **Animations**: Framer Motion
- **CMS**: Payload CMS v3 (PostgreSQL adapter)
- **State**: React Context for Client State (e.g., Shortlist, Cursor, Language)
- **Language**: Bilingual support (English & Bengali)
