# Model Switch Protocol

When a new Antigravity model or chat session is initialized, follow this strict protocol to immediately absorb the project context without relying on the previous conversation history.

## 1. Initial State Loading
- Automatically read `docs/PROJECT_STATE.md` to understand the architecture and current progress.
- Read `docs/ACTIVE_TASK.md` to understand the immediate goal.
- Check `docs/SESSION_HANDOFF.md` for exact details on where the previous agent stopped.

## 2. Rules & Constraints Check
- Read `docs/FINAL_ZERO_COST_MASTER_DECISION.md` and `docs/FREE_TIER_MATRIX.md` to ensure any proposed architecture adheres to the zero-billing constraints.
- Review `docs/KNOWN_ISSUES.md` to avoid repeating past mistakes (e.g., hydration issues, broken shaders).

## 3. Communication Standard
- Do not apologize or generate excessive boilerplate text.
- Be highly decisive.
- Update `SESSION_HANDOFF.md` before terminating the session or upon completing major milestones.
